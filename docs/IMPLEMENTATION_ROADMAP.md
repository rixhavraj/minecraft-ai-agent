# Implementation Roadmap

1. Phase 0 audit: COMPLETE (documentation, runtime, dependency, and limitation inspection).
2. Phase 1 parallel foundation: PARTIAL / UNIT TESTED. Shared state, event bus, observation coordinator, parallel orchestrator, read-only monitors, lifecycle contract, and orchestration boundary added.
3. Phase 2 perception: consolidate existing state controllers behind the shared world state; add stale-state validation.
4. Phase 3 execution: expand postcondition verification and bounded recovery.
5. Phase 4 survival: controlled-world live validation for threats, night, bed, food, death, and resume.
6. Phase 5 language: expand schema/fixtures and model structured-output validation.
7. Phase 6 planning: resource-aware hierarchical planning and progress watchdog.
8. Phase 7 memory: spatial/procedural memory and restart progress reconciliation.
9. Phase 8 learning: validated reusable strategies and measured improvement.
10. Phase 9 Telegram: live authorization, progress, and failure acceptance.
11. Phase 10 daily life: live day/night routine acceptance.
12. Phase 11 reliability: long-run, reconnect, and performance testing.

Each phase must retain the labels IMPLEMENTED, UNIT TESTED, INTEGRATION TESTED, and LIVE MINECRAFT VERIFIED separately.
